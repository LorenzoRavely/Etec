Conceitos principais

Clique em cada item para ler a explicação.

O que é um qubit?

É o "bit quântico". Além de 0 e 1, ele pode estar em uma combinação dos dois, descrita por números chamados amplitudes.

O que é superposição?

É quando o qubit está em uma combinação de estados. Ao medir, o resultado aparece como 0 ou 1, com probabilidades que dependem das amplitudes.

O que é emaranhamento?

Dois qubits emaranhados formam um só sistema. Medir um deles dá informação sobre o outro, mas isso não permite enviar mensagens mais rápido que a luz.

O que é interferência?

Os algoritmos quânticos combinam as amplitudes para que os caminhos que levam à resposta certa se reforcem e os errados se cancelem.

O que é decoerência?

É a perda do estado quântico por causa da interação com o ambiente (calor, vibração, radiação). É um dos maiores obstáculos da área.
