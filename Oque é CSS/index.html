O que é CSS?

Seletores, Propriedades e Valores

1. O que é CSS

CSS significa Cascading Style Sheets, ou seja, "Folhas de Estilo em Cascata". É a linguagem usada para deixar as páginas da internet bonitas. Enquanto o HTML é responsável pelo conteúdo (textos, imagens, botões), o CSS é responsável pela aparência desse conteúdo: cores, tamanhos, espaçamentos, fontes, e como os elementos ficam posicionados na tela.

Sem o CSS, uma página fica apenas com textos pretos em fundo branco, sem nenhum estilo. O CSS é o que dá vida e identidade visual ao site.

2. Como o CSS é organizado

Toda regra de CSS segue basicamente esta estrutura:

seletor { propriedade: valor; }

Vamos entender cada parte:

3. Seletor

O seletor indica qual elemento da página vai receber o estilo. Pode ser uma tag do HTML, uma classe ou um id.

p { color: blue; }

Nesse exemplo, p é o seletor e está dizendo: "todos os parágrafos da página vão ficar azuis".

4. Propriedade

A propriedade é a característica que queremos alterar, por exemplo: cor, tamanho da fonte, largura, altura, espaçamento etc.

p { color: blue; }

Aqui, color é a propriedade. Estamos falando que queremos mudar a cor.

5. Valor

O valor é a informação que define como a propriedade vai se comportar. É a resposta para a propriedade escolhida.

p { color: blue; }

Aqui, blue é o valor. Estamos dizendo qual cor queremos: azul.

6. Exemplo na prática

Olha esse quadrado azul abaixo. Ele foi estilizado só com CSS:

.quadrado-demo { width: 100px; height: 100px; background-color: #3498db; border-radius: 10px; }
  • .quadrado-demo → seletor (classe)
  • width, height, background-color, border-radius → propriedades
  • 100px, #3498db, 10px → valores

7. Resumindo

  • Seletor: quem vai ser estilizado
  • Propriedade: o que vai mudar
  • Valor: como vai mudar
