Sobre o Bootstrap

O Bootstrap é um framework front-end, ou seja, um conjunto pronto de CSS e um pouco de JavaScript que ajuda a construir páginas web sem precisar escrever todo o estilo do zero. Ele foi criado em 2011 por desenvolvedores do Twitter e hoje é um dos frameworks mais usados no mundo.

Com o Bootstrap, você monta a página combinando classes prontas: um sistema de grid de 12 colunas pra organizar o layout, e componentes já estilizados como botões, cards, navbar, alertas e formulários.

Principais características
  • Sistema de grid responsivo
  • Componentes prontos (botões, cards, navbar, etc)
  • Classes utilitárias pra espaçamento, cor e texto
  • Funciona bem em qualquer navegador e tamanho de tela
